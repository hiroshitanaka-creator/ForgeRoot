# User Decision Card Template

ユーザーに判断を求めるとき・ターンを締めるときの必須形式。
Skill使用時、Claudeは毎ターンの最後にこれを出す(Output contract)。

```markdown
## User Decision Card

推奨: <A/B/Cのどれを推すか + 理由1行>

選択肢A: <内容>(危険度: <class> / 戻せるか: <はい・いいえ・方法>)
選択肢B: <内容>(危険度: ... / 戻せるか: ...)
選択肢C: <内容>(危険度: ... / 戻せるか: ...)

危険度: <このターン全体の危険度と、class C/D該当の有無>

次にあなたがすること:
  <ボタンの場所・貼る言葉・読むファイルを具体的に。例:
  「進めて」と返信する / PR #8 ページで Ready for review を押す>

Claudeが次にすること:
  <あなたの返答を受けてClaudeが実行する内容>

止めるべき条件:
  <これが起きたら「halt」と言ってください、という条件>
```

## 運用ルール

- 選択肢は最大3つ。2つで足りるなら2つでよい
- 各選択肢に「戻せるか(可逆性)」を必ず書く
- 判断不要な報告ターンでも「次にあなたがすること」「Claudeが次にすること」は埋める
- class C/D の変更を含む選択肢には ⚠ を付けて明示する
```
