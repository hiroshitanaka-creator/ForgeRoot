# Next Action Card(次アクションカード)

非エンジニアのオーナーに「次の一手」を提示するときの形式。1枚 = 1アクション。

```
## Next Action Card

現在地:
  <mainの最新タスク / open PRの状態を1〜3行で>

次の一手:
  <タスク名を1行で。例: T047 tool-routing mutator の bounded PR を作る>

なぜ今これか:
  <Priority rule上の根拠と出典(handoff / task source / blueprint節番号)>

危険度:
  <class A/B/C/D + 一言理由>

私(Claude)がやること:
  1. <具体的ステップ>
  2. ...

あなたに決めてほしいこと:
  <ユーザー判断が必要な点。なければ「なし(draft PRまで進めてよければ『進めて』と返信)」>

コピペ用コマンド:
  <ユーザーが貼るだけでよい指示文またはコマンド。なければ「不要」>

所要目安:
  <Claudeの作業目安と、ユーザーの確認にかかる目安>

止めるべき条件:
  <これが起きたら中断してユーザーに戻す、という条件>
```

## 運用ルール

- 1枚に2つ以上のタスクを入れない
- 「次の一手」は必ず実行可能な粒度(1 bounded PR以内)にする
- 専門用語には一言翻訳を添える
